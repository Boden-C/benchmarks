Conversationalist Prompt

This prompt is built on Meta's 24 Karat prompt, built specifically for human preference. It is less robotic and more chatty. 



Note: It is **not** recommended you use this with Qwen 3 or GLM-4.6 - they already have a naturally stylistic tone, using the prompt often makes it too whimsical. Gemini 2.5 Pro won't be overly whimsical, but it also won't significantly improve it.
